## Inventory Manager

A C# console application designed to practice Object-Oriented Programming (OOP) fundamentals, collection management, and CLI user interface design. 

### Key Features (In Development)
* **Product Catalog:** View detailed inventory listings including stock quantities and prices.
* **Product Management:** Add new items with structured validation.
* **Search & Filter:** Search items by ID or name and locate specific categories.
* **Stock Updates:** Track stock levels and receive low-inventory alerts.

### Built With
* C# / .NET
